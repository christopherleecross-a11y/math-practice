@@ calc-2-1 | Example 1
f′(2) = lim(x→2) (f(x) − f(2))/(x − 2) || Example 1. The derivative at 2 is the limit of the slope between x and 2.
f(2) = 8 − 10 = −2 || f of 2 is 2 times 4 minus 10: negative 2.
(2x² − 5x + 2)/(x − 2) = (2x − 1)(x − 2)/(x − 2) || Subtracting negative 2 adds 2. Factor the top.
= 2x − 1 → 2(2) − 1 = 3 || x minus 2 cancels. As x goes to 2, 2 x minus 1 goes to 3.

@@ calc-2-1 | Example 2
(x³ − 1)/(x − 1) = (x − 1)(x² + x + 1)/(x − 1) || Example 2. Find the slope at 1. Factor the difference of cubes.
= x² + x + 1 → 3 || x minus 1 cancels. At x equals 1, that's 3.
y − 1 = 3(x − 1) → y = 3x − 2 || Point slope form with slope 3 through 1, 1. Simplify: y equals 3 x minus 2.

@@ calc-2-1 | Example 3

f′(1) = −1/1 = −1 || At x equals 1, the slope is negative 1.
y − 1 = −1(x − 1) → y = −x + 2 || The tangent line is y equals negative x plus 2.

@@ calc-2-2 | Example 1
f′(x) = lim(h→0) (f(x + h) − f(x))/h || Example 1. Use the limit definition of the derivative.
[(x + h)² − 3(x + h) − x² + 3x]/h || Substitute. The minus sign changes both signs of f of x.
= (2xh + h² − 3h)/h || Expand. The x squared and 3 x terms cancel.
= 2x + h − 3 → 2x − 3 || Divide by h, then let h go to 0.

@@ calc-2-2 | Example 2
(√(x + h) − √x)/h · (√(x + h) + √x)/(√(x + h) + √x) || Example 2. Multiply by the conjugate.
= h/(h(√(x + h) + √x)) || The top becomes x plus h minus x, which is h.
= 1/(√(x + h) + √x) → 1/(2√x) || h cancels. As h goes to 0, the bottom is 2 root x.
domain of f′: x > 0 || At x equals 0, the denominator is 0. So f prime exists only for x greater than 0.

@@ calc-2-2 | Example 3
f′(x) = 2x − 4 || Example 3. Using the definition like Example 1, the derivative of x squared minus 4 x is 2 x minus 4.
x < 2: f′ < 0 → f decreasing || For x less than 2, f prime is negative, so f is going down.
x = 2: f′ = 0 → horizontal tangent || At 2, the slope is 0: a horizontal tangent at the vertex.
x > 2: f′ > 0 → f increasing || For x greater than 2, f prime is positive, so f is going up.
